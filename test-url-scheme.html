📖 故障排查步骤

步骤 1: 检查 RustDesk 安装

确保 RustDesk 已正确安装在以下位置之一：

C:\Program Files\RustDesk\rustdesk.exe
C:\Program Files (x86)\RustDesk\rustdesk.exe
%LOCALAPPDATA%\RustDesk\rustdesk.exe

步骤 2: 检查浏览器设置

某些浏览器默认会阻止外部协议：

  • Chrome: 在地址栏右侧可能有提示图标
  • Edge: 会弹出确认对话框
  • Firefox: 需要在设置中允许

步骤 3: 使用 PowerShell 测试

打开 PowerShell 并运行：

Start-Process "rustdesk://connect/1074305050?password=xiehan12"

步骤 4: 使用命令行参数（替代方案）

如果 URL Scheme 不工作，可以直接使用命令行：

"C:\Program Files\RustDesk\rustdesk.exe" --connect 1074305050 --password xiehan12

步骤 5: 注册 URL Scheme

如果还是不行，可能需要手动注册。使用管理员权限运行：

.\Test-URLScheme.ps1 -DiagnoseOnly

🔍 常见问题

❓ 点击链接后没有任何反应

可能原因：

  1. URL Scheme 未注册 - 运行 Test-URLScheme.ps1 诊断
  2. 浏览器阻止 - 检查地址栏是否有提示图标
  3. RustDesk 版本不支持 - 确保使用 Flutter 版本
❓ 浏览器弹出"找不到应用程序"

解决方案：

  1. 检查 RustDesk 是否已正确安装
  2. 重新安装 RustDesk 以注册 URL Scheme
  3. 手动注册 URL Scheme（见上方步骤 5）
❓ RustDesk 打开了但没有自动连接

可能原因：

  1. 使用的是 Sciter 版本 - 请使用 Flutter 版本
  2. 密码包含特殊字符 - 尝试不带密码的连接
  3. ID 错误 - 确认远程设备 ID 正确
✅ 推荐做法：
  • 使用 PowerShell 脚本 Test-URLScheme.ps1 进行完整诊断
  • 首次使用建议不带密码测试：rustdesk://connect/<ID>
  • 确认 URL Scheme 工作后再添加密码参数
