🚀 RustDesk Web Client 自动连接

通过 URL 参数实现自动填充 ID 和密码，并可选自动连接

📝 配置连接参数

📋 生成的 URL：

📚 使用示例

1. 仅预填充 ID

https://yourserver.com/#/?id=123456789

2. 预填充 ID 和密码

https://yourserver.com/#/?id=123456789&password=yourpassword

3. 自动连接（预填充 + 自动连接）

https://yourserver.com/#/?id=123456789&password=yourpassword&autoconnect=true

4. 强制中继连接

https://yourserver.com/#/?id=123456789&relay=true&autoconnect=true

📖 参数说明

参数名 说明 示例
id 远程设备 ID（必需） 123456789
password 连接密码（可选） yourpassword
autoconnect 是否自动连接 true 或 false
relay 是否强制中继 true 或 false
⚠️ 安全提示： 密码会以明文形式出现在 URL 中，建议仅在可信环境下使用，或使用临时密码。在生产环境中，建议不在 URL 中包含密码，而是让用户手动输入。
